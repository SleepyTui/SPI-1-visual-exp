# 曲谱记录

- `ode.ly`：https://www.mutopiaproject.org/ftp/BeethovenLv/ode/ode.ly ，Peter Chubb 制谱，文件声明 Public Domain。取 sop 首四小节，G→C：E E F G | G F E D | C C D E | E(1.5) D(0.5) D(2)。
- `auld.ly`：https://www.mutopiaproject.org/ftp/HoretzkyF/horetzky31/horetzky31.ly ，Stan Sanderson 制谱，源 Boije collection #268，文件声明 Public Domain。取 upper 弱起后的首四小节高声部，D→C，保留 2/4 与附点节奏，省去弱起。
- NEW BRITAIN：https://hymnary.org/tune/new_britain ，页面列 Public Domain、曲调首句与五声说明；对照其可下载谱首四个完整小节，移至 C，省去弱起。3/4：C(2) E(.5) C(.5) | E(2) D(1) | C(2) A低(1) | G低(2) G低(1)。
- `greensleeves.ly`：https://www.mutopiaproject.org/ftp/Traditional/greensleeves/greensleeves.ly ，Steve Dunlop 制谱，文件声明 Public Domain。仅研究，原谱含变化音，未并入纯音阶试听。
- `bourree.ly`：https://www.mutopiaproject.org/ftp/BachJS/BWV996/bourree/bourree.ly ，Rudy Matela 等制谱，文件声明 Public Domain。仅研究，混用小调音级，未并入纯音阶试听。

试听采用三个曲调的四小节旋律；移调、配器与伴奏由 Demo 新写，没有使用原曲录音。事件数组位于 `music-excerpts.js`，可逐音校对。核对日期：2026-10-18。
