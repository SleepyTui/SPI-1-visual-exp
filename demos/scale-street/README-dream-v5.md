# 梦游音阶长街

在既有 16 个家族、65 个音阶的交互基础上，重制界面、玻璃灯管结构、内部灯效和街景色彩。所有招牌和图标仍为原生矢量；文字保持当地语言和字体。界面的中英文切换只作用于说明和菜单。

## 运行与入口

直接双击 `index.html` 即可离线打开。也可以在工程目录运行 `node serve.mjs`，打开 http://127.0.0.1:4178/ 。声音由点击启动；不自动播放。查看新设计时，如果页面已打开，请刷新。

预览为实际 320×320 或 640×640 像素。初次在宽屏打开默认 640，较窄屏幕默认 320；以后保留自己的尺寸选择。小屏查看 640 时可以横向滚动。横向滑条选择家族，纵向滑条选择家族内音阶。选中招牌后开启单选和透明信息卡；“全亮检视”展示全街独立灯效。

## 本版视觉与控制

界面以暖灰纸色、淡紫与薄荷青构成外壳，深色控制台分为景观、灯光、声音、布局。场景使用高低分开的建筑、彩色立面反射、中心天光、薄雾、轻颗粒与直线车流。每个招牌沿用建筑与传统纹样的身份，重绘有电极间隙的复线灯管、玻璃管暗边、彩色发光管与细亮芯。

“灯光”默认使用独立灯效程序：檐下流云、花见灯笼、潮汐回声、织锦星火、铜锣涟漪、莲瓣舒展、孔雀开屏、月拱回廊、玻璃阶梯、午夜钟楼、丝绒回旋、蓝调切分、风琴织光、六瓣光轮、八面星环、爵士快门。十六套程序各自拥有 4.9–11.2 秒基础周期、不同空间顺序、相位和停顿。程序以实际 SVG 发光段的颜色亮度变化运行，不改变牌体或支架透明度。文字的明暗变化较纹样克制，保持可读。每个家族下音阶变化也改变内部节拍纹样和相位。

全局速度与变化幅度可统一调整，也可在“此牌独立灯效”覆盖当前招牌；常亮、呼吸、跑马、随机、闪烁仍保留。开启系统减少动态效果时，网页停用内部跑马与车流移动。导出的独立动态 SVG 使用 SMIL，脱离网页后按 SVG 自身动画播放；如需静态导出，请在街景先设为常亮并关闭车辆动画，再导出当前街景。

景观中可调整街道雾光、胶片颗粒、天空辉光、楼宇颜色、窗灯和车流。布局保留每块牌的位置、缩放，以及所有牌围绕各自中心缩放，支架随牌运动。灯管外轮廓和内部线宽独立调整。其他原有功能包括远景模糊、透明弹窗、音阶图、随机音阶、试听和四轨环境声自动压低。

“导出全部参数 JSON”保存当前选择、全部视觉参数、布局、全局和个体灯效、试听与环境声设置。新版浏览器存储使用独立键，原版浏览器设置不被覆盖；可以通过载入旧版 JSON 恢复旧参数，新参数补默认值。浏览器实时播放进度不属于导出的设置。

## 资源与源码

`assets-native/` 包含 260 张招牌 SVG、65 个 32×32 单色图标、4 张街景 SVG。原生字体路径及布尔文字缓存沿用；霓虹 SVG 包含内部纹样动画，无远程依赖，无嵌入位图。`manifest-v2.json` 是更新后的资源清单。

- `dream-art-v5.js`：分段复线玻璃灯管、十六套纹样、梦境色板与街景光场。
- `dream-circuits-v5.js`：可重复的十六套灯效时序，生成 SVG 和网页共同使用。
- `dream-motion-v5.js`：单选/全亮、全局/个体控制和系统减少动态效果适配。
- `dream-ui-v5.js`、`dream-ui-v5.css`：新版界面与分组控制台。
- `art-v2.js`、`app-v2.js`、`controls-v3.js`：原生矢量、交互、参数验证与持久化。
- `audio-v2.js`、`ambience-v4.js`：既有音阶试听、四轨街道音景。

生成资源：`node generate-v2.mjs`。资源检查：`node verify-v2.mjs`。当前浏览器检查：`node qa-dream-v5.mjs`。打包：`python package_v2.py`，输出 `scale-street-dream-v5.zip`。浏览器检查脚本使用本机 Edge 与安装好的 Playwright，路径可按机器调整。

## 来源与边界

视觉参考是用户提供的霓虹 GIF 与图片；GIF 抽取多个时刻观察了内部灯珠和短管的接力亮起。新增纹样、灯管、场景与界面由代码绘制，没有把参考图片嵌进 SVG。参考照片留在“灵感札记”供私有设计对照，其原始版权不因本工程转移。

字体许可保存在 `font-sources/`；地图和原有资料来源见 `README-v2.md`。三条 CC0 环境声的作者、原始来源及许可在 `ambience/SOURCES.json`，第四条远处店铺音乐为原创合成。试听仍包含三个有曲谱来源的公版旋律示例，其余为原创音阶练习；不把所有 65 个音阶宣称为传统演奏复原。

本轮浏览器检查覆盖视觉和交互，不代替用户对美术风格和音频听感的最终判断。具体记录见 `VALIDATION-dream-v5.md` 与 `test-output-dream-v5/report.json`。
