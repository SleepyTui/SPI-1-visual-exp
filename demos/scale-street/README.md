# 音阶长街 · 三种夜色

第一阶段的原创视觉样稿，供选择后续全量制作的视觉方向。当前交付 48 张招牌 SVG、12 个 32×32 单色 Icon、12 张整街 SVG，以及交互比较网页；完整目标为 65 个音阶、325 个核心 SVG，本阶段尚未展开全量。

## 打开与比较

直接用 Edge、Chrome 等桌面浏览器打开 `index.html`。页面不依赖网络、远程字体或在线音源。也可在本目录执行 `npm start`，打开终端显示的本机地址。

“街景试映”切换三种风格、2D／2.5D、灯箱／霓虹，以及实际 320×320／640×640 预览。小窗口中的 640 预览保持实际尺寸并允许在预览容器内滚动，不自动缩成 320。

“招牌对照”按四个音阶比较同一设计的四种组合，支持放大和逐个下载。Icon 以实际 32×32 显示。“选择方向”保存本机选择与备注，导出 JSON 选择单后可用于下一阶段。`overview.svg` 为四音阶、三方向的2.5D灯箱总览。

## 本阶段的内容边界

四个精细音阶为中国 Gong、日本 Hirajōshi、中东 Rast、Whole Tone。16 个街景位置中，其他 12 个家族明确标为 DRAFT，只有构图草案，不提供该家族的精细变体、Icon 或声音。草案家族的横向滑条只浏览旧目录资料，不改变招牌，其标签注明“目录草稿”。目录数据目前仍为57条，补齐65条、全面校核资料及全量制作在视觉选择之后进行。

全亮检视用于评估配色；点击招牌自动进入单选体验，仅选中家族亮起。纵向滑条选择家族。展开半透明菜单查看地域、时期、音符数、音高环及音分。320菜单可滚动，收起后16块招牌完整显示，菜单入口在方屏外。

当前招牌支持50%—150%缩放、横纵位移；变换限制在方屏内，两种空间表现独立保存，灯光版本共用布局。手动编辑允许牌间重叠，复位恢复默认构图。色调调整仅影响街景；下载链接提供原始、未应用本机编辑的样稿SVG。选择单包含本机布局设置。

## 三套视觉语言

- 港湾旧招：书写字、珐琅、暖光、檐牌与悬挑结构。
- 夜航新街：透明框、偏心轨道、蓝紫冰青与轻盈留白。
- 电光构成：大字、箭头、切角、强色块与折板结构。

两种空间表现都为SVG。2D采用平面街巷构成；2.5D采用固定中心消失点的手工矢量投影和立体侧面。透视体现约100mm长焦的压缩观感，没有物理镜头、真实三维光照或漫游相机。

本阶段没有收到用户提到的街景与招牌参考图片，样稿依据文字方向原创。正式定稿应在参考图补充后检查轮廓、字形与街景密度。

## 声音与音乐资料

四个精样各有一种Web Audio合成音色和一段4/4、96 BPM、16拍的短旋律，主体10秒，默认关闭。开启声音后，切换精样播放一次；快速切换取消旧声并短暂淡出。它们是原创合成演示，未使用民族乐器采样，也未完整模拟传统演奏语法。

统一以C为主音。Gong：0/200/400/700/900 cents；Hirajōshi：0/200/300/700/800；Rast：0/200/350/500/700/900/1050，为24等分教学近似；Whole Tone：0/200/400/600/800/1000。Hirajōshi的西方音阶归纳存在转位定义差异；Maqam的真实调律随演奏语境变化。时期描述保持概括，不声称统一精确发源年份。其余目录条目尚待全面校核。

主要参考：

- [Maqam World · Rast](https://www.maqamworld.com/en/maqam/rast.php)：Rast 的音阶与 ajnas 结构。
- [Open Music Theory · Collections](https://viva.pressbooks.pub/openmusictheory/chapter/collections/)：全音、五声和八声集合。
- [Music Theory for the 21st-Century Classroom · Jazz Scales](https://musictheory.pugetsound.edu/mt21c/JazzScales.html)：后续爵士音阶目录校核参考。

## 文件与可编辑来源

`assets/`按照方向、空间表现、灯光和音阶组织，`manifest.json`记录全部72个样稿文件。所有招牌与街景文字已转为路径，SVG不含位图、外链字体或文字标签。32×32 Icon为透明底单色线条。

`sample-art.mjs`负责原创图形、排版和街景结构；`generate.mjs`统一输出资源与离线页面数据。`prepare_fonts.py`从Google Fonts官方仓库获取源字体、进行字形连接并导出字形缓存；`glyphs.json`是已生成的路径缓存。网页通过本地脚本读取已生成数据，不使用浏览器fetch，因此支持file://打开。

字体为 Ma Shan Zheng、Shippori Mincho、Aref Ruqaa、Bungee、ZCOOL QingKe HuangYou、DotGothic16、Reem Kufi、Space Grotesk、ZCOOL KuaiLe、Dela Gothic One、Lalezar、Anton。原始文件、版权与OFL许可证保留在 `font-sources/`；来源映射在该目录的 `SOURCES.json`。阿拉伯字形使用HarfBuzz连接后转曲。文字生成遇到缺字立即报错，不静默替换为空白。

从现成缓存重新生成SVG无需安装依赖：`npm run generate`。若重新下载字体并制作缓存，需要Python的fonttools和uharfbuzz，可安装在项目本地`.tools`后执行`prepare_fonts.py`。

## 验证与交付

`npm run check`验证资源数量、32像素Icon、全部文字转曲、无位图／外链、唯一SVG ID、图形引用及16个家族位置。浏览器验证记录与实际截图保留在`test-output/`，摘要见`VALIDATION.md`。

浏览器验证脚本采用本机应用提供的Playwright和隔离的无头Edge，未读取现有浏览器资料；脚本中的运行库和浏览器路径需要在另一台电脑运行验证时调整。浏览器实际预览已完成；主观审美、文化风格与音色喜好仍由用户在样稿中选择。
