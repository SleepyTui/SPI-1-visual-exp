# 音阶长街：弹窗、楼宇与风格控制版

在工程目录运行 `node serve.mjs`，打开 http://127.0.0.1:4178/；也可以直接打开 `index.html` 离线使用。当前完整包为 `scale-street-studio-v6.zip`，原梦游版资源包保留。

## 当前参数成为默认值

本版首次在原浏览器刷新时，自动读取此前已保存的完整参数，作为你的默认值：包括色相、楼窗参数、楼宇调色、全部招牌布局、试听设置和当前选择。当前已保存参数优先，因此不会因为升级回到初始效果。

使用本地预览服务时，这份默认值同时写入 `user-defaults-v6.json` 和 `user-defaults-v6.js`，并重新生成完整工程包。文件是可检查的普通 JSON/JavaScript。新浏览器或解压后的工程使用该默认文件。直接 file:// 打开时，默认值保存在该浏览器，仍可以导出完整 JSON 带走。

“当前参数设为默认”可以再次更新默认值；“恢复默认参数”回到自己的默认值。默认不包含正在播放到第几秒，声音仍由手势启动。参数文件仅由同源、本地、带专用请求头的页面保存到两个固定文件，没有任意文件写入接口。

## 弹窗与上下滚动选择

弹窗取消了底部试听、四小节进度和主音那一行；声音面板里的播放、音量与重播保留。具体音阶改为有中心选中带的上下滚轮，支持鼠标滚轮、触摸滚动、点击项目和键盘上下键，与纵向滑条同步。

布局面板加入弹窗宽度、高度、X/Y 偏移、圆角。尺寸和位置会根据当前 320/640 方屏安全约束，保留 6 像素边距；不通过拉伸或整体缩放文字来适配。较矮的卡片采用紧凑排版，宽矮的卡片将元数据与音程图分栏。范围内的极端尺寸也保留可读内容。

## 建筑体积与逐窗动画

左右建筑拥有加深的侧立面、透视屋顶、侧面楼层线和窗户，可以调整楼宇纵深厚度。窗灯不再依赖原先细微、长周期的 CSS 亮度变化；改用独立窗口的可重复色光时序，正面和侧面窗户均参与。

模式包括住户随机开关、错相呼吸、楼层波浪、逐层流光、星点明灭和常亮。可调整亮灯比例、速度、变化幅度、基础亮度、暖/冷灯颜色和扩散。楼体轮廓保持稳定，变化作用于发光窗格。

## 整体视觉风格

新增独立“风格”页签，包含整体染色与强度、饱和度/对比度/明度、天空与路面具体颜色、柔焦、辉光颜色与扩散、实体轮廓粗细与颜色，以及纸感划痕、颗粒、暖褐调、褪色抬黑、暗角和扫描线。整体辉光对亮部进行提取后晕染；实体轮廓控制影响建筑和牌体，霓虹灯管自己的内/外线宽仍独立保留。

所有新增参数继续进入同一份完整 JSON；街景 SVG 导出包含滤镜、窗灯与内部招牌灯效。整体风格只作用于街景，信息卡文字不会跟随被做旧或模糊。

## 验证与资源

运行 `node generate-v2.mjs` 生成 260 张招牌、65 个图标和4张街景；`node verify-v2.mjs` 检查资源；`node qa-studio-v6.mjs` 检查当前交互。浏览器截图与报告保存在 `test-output-studio-v6/`，保留了既有灯效、音频和离线验证记录。

字体、环境声和既有曲谱来源见 `README-dream-v5.md`、`README-v2.md` 和 `ambience/SOURCES.json`。前一版完整工程保存在 `scale-street-dream-v5.zip`；更早的完整目录备份仍在同级 `scale-street-backups/`。
