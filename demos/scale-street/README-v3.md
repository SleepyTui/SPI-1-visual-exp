# 世界音阶长街 · 城市夜晚氛围版

直接打开 `index.html`，或在本目录执行 `npm start`，访问终端显示的地址。网页离线运行，字体、地图、音色与图形均为本地资源。预览保持实际 320×320、640×640 CSS 像素，小窗口可横向滚动查看 640 预览。

## 横向选家族，纵向选具体音阶

下方横向滑条选择 16 个家族，左侧纵向滑条选择当前家族的具体音阶，纵向范围随家族更新。点击招牌、家族列表、随机按钮和弹窗选择框均同步两个滑条。切换时一起更新完整招牌、32 像素图标、音程图和试听。各家族保留上次选择，随机从 65 条中等概率抽取并排除当前条目。

语言开关只翻译界面与弹窗资料。招牌及图标固定使用当地文字和字体。传统家族采用汉字、日文、埃塞俄比亚文、印尼拉丁文字、泰文、天城文与阿拉伯文，跨地域现代调式保留通用英文标识。

## 字体保持比例，文字先做布尔并集

街景具有 16 栋高度、宽度与楼层数各异的建筑，保留楼间缝隙、回转侧面、窗格、店面、空调和悬挑钢架。招牌使用建筑与传统纹样的复合轮廓，以单一等比例缩放装入街景，不拉伸字体。32×32 图标对招牌轮廓作方形简化适配，原文字形仍等比例。

每个完整招牌的主字、副字先经 HarfBuzz 塑形与统一布局，再由 Skia PathOps 真实计算路径并集，去除重叠区域内部接缝。字内孔洞保留，外边界与内孔边界分别缓存；霓虹沿合并后的结果描线，灯箱使用同一并集填色。并集不会人为连接原本分离的笔画。缓存见 `lettering-cache.js`，计算记录见 `lettering-report.json`。

`assets-native/` 包含 **260 张招牌 + 65 个单色图标，共 325 个核心 SVG**，另有 4 张街景 SVG，索引见 `manifest-v2.json`。招牌为 320×320，图标为 32×32，全部字形转曲，无位图、外部字体和远程依赖。2D／2.5D × 灯箱／霓虹形成四种组合。空间是矢量表现，背景在两种模式中均保持一点透视，未声称真实物理相机。

## 视觉参数、布局与试听设置可保存 JSON

控制工具位于方屏外，桌面右栏可独立滚动，方便一边调节一边看街景。

| 控制 | 范围与作用 |
|---|---|
| 背景楼宇 | 饱和度、对比度、明度各 0–200%，色相 0–360°；独立于招牌和车灯，可一键复位 |
| 招牌外轮廓 / 内部线条 | 各 0–8，外轮廓只控制整块招牌的边框；内线控制全部合并文字、字内孔边界与传统纹样 |
| 光晕 | 0–12 个招牌坐标单位，0 关闭光晕 |
| 远景模糊 | 0–8 个街景坐标单位，近景清晰，按预设远近层级递增高斯模糊 |
| 全部招牌中心缩放 | 50–150%，每牌围绕自身图形中心缩放，位置不漂移；可叠加单牌缩放，支架同步变换 |
| 楼窗灯光氛围 | 开关、变化幅度 0–0.6、速度 0.1–2 倍、基础亮度 0–2，各窗相位错开 |
| 全局灯效 | 常亮、呼吸、跑马、随机明暗、灯管闪烁；速度 0.2–4 倍，幅度 0–1 |
| 单牌灯效 | 跟随全局或独立设置模式、速度、幅度；仅点亮的霓虹牌播放灯效 |
| 车灯与车辆 | 直线光轨、模糊剪影、车灯共用运动时钟和透明度包络；动画、速度、模糊、色相、总透明度、透明度起伏、剪影模糊及同屏 1–16 辆分别控制 |
| 色相 | 全街 0–360°，车灯还可追加独立偏移 |
| 单牌布局 | 缩放 50–150%、X/Y 位移、单牌与全局复位；两种空间模式分别保存 |
| 透明卡片 | 背景不透明度 0–85%、背景模糊 0–24px，独立于文字透明度 |

灯效只对发光灯管、文字、边框和纹样调节 RGB 发光强度与饱和度，牌底、金属侧面、支架保持稳定不透明；不再用整体透明度模拟呼吸。随机明暗采用各牌不同的确定性伪随机序列，使相同参数可以复现。动画遵守系统减少动态效果设置。景深使用预设距离层级，不模拟光圈。

“保存 JSON”导出带 `schema`、`version` 和 `settings` 的文件。“载入 JSON”恢复全部视觉、布局、家族选择、每家族音阶、预览尺寸、语言、音量、声音开关、速度倍率、曲目模式和伴奏开关。输入经字段白名单与范围检查；错误文件不覆盖当前设置。同样的参数自动保存在本机浏览器。导入或刷新不自动发声，点击选择或播放才触发试听。

街景导出保留当前布局、描边、光晕、景深、灯效、车灯与色调；单牌下载保留当前描边和光晕参数。压缩包里的 SVG 使用默认参数，JSON 可另存多个预设。手动编辑允许重叠，默认布局牌面无交叠。

## 信息卡用实际音程绘制多边形

信息卡为 282×282，居中完整放入 320 画面。地域、时期、音数采用等宽等高三列；图标框均为 40×40，标签行高度一致且中心对齐。地图下显示本地化地域名称，年代不可靠时保留“传统”“古代”等概括，不虚构精确世纪。

音数图形把一个八度映射为一圈，音高 `n` 的角度为 `n/12 × 360°`，依次连接当前音阶各音级，与下方音分关系图使用同一数组。不等距音阶自然呈现不规则多边形，全音等对称集合保持对称；微分音保留分数角度，数字显示音符数量。

## 试听按家族改变速度、节奏与旋律

16 个家族分别配置合成音色、速度、节奏、旋律轮廓、音域与发音长度。原创练习为四个 4/4 小节，基础速度 **58–144 BPM**，速度倍率可调 50–160%。每个具体音阶通过集合和变体产生不同旋律。自然调式、和声小调、旋律小调、Blues、六声、对称集合、Bebop 等加入原创和弦或琶音与低音，可关闭伴奏。全部旋律与伴奏音符均来自当前音阶。

“曲谱片段优先”目前在三个条目采用公开领域曲调：

| 条目 | 四小节旋律 | 拍号与处理 |
|---|---|---|
| Gong | 《友谊地久天长》 | 2/4，Horetzky 吉他谱高声部，D→C，省略弱起 |
| Major / Ionian | 《欢乐颂》 | 4/4，公开合唱谱高声部，G→C |
| Major Pentatonic | 《奇异恩典》NEW BRITAIN | 3/4，移至 C，省略弱起 |

片段比较相容的音高集合，不表示作品源自所选家族地域。伴奏为 Demo 新配，未复制原谱和声。其余条目明确标为“原创四小节音阶练习”，也可全局选择原创模式。四小节的时长和进度随拍号、速度变化，不再固定为 10 秒。

《绿袖子》和巴赫 BWV996 原谱也保存在 `music-sources/` 供比对，含混合小调或变化音，未强行作为单一纯音阶的试听。当前并非每个音阶都有经典片段。

声音默认关闭，快速切换取消旧排程并淡出。Rast 半降音、泰国七等分、Sléndro 理想化模型保留浮点音高与指数频率。传统家族试听仍为集合练习，未模拟完整 Raga／Maqam 语法或传统乐器采样。

## 四轨环境声与音阶试听自动避让

“街道环境声 · 四轨混音”提供脚步与人流、车辆经过、人群说话、远处店铺音乐四个独立音量，以及环境总音量和“试听时背景保留音量”。开启环境声后，同时启用音阶试听；此后选择音阶会播放乐段，背景快速降低到所设比例（默认保留 20%，约 −14 dB），结束或停止后平滑恢复。音阶试听和环境声各有开关。

前三轨为已核对源页面 CC0 声明的通用采样，店铺音乐为原创合成循环，不使用第三方音乐录音。作者、地址、许可与校验值见 [采样记录](ambience/README.md) 和 `ambience/SOURCES.json`。音效嵌入本地脚本，支持直接离线打开；首次点击后解码，循环接缝交叉淡化。环境声不是香港实地录音，也不模拟特定人的说话内容。

所有轨道音量、总音量、压低比例、楼窗灯光、车流及整体招牌缩放统一包含在“导出全部参数 JSON”中，不需要分别导出每块招牌。刷新或载入参数不自动发声。

## 来源和重建入口

用户照片位于 `references/`，仅作设计参考，未嵌入招牌和街景 SVG。OFL 字体及授权位于 `font-sources/`；地图来自 [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/)。曲谱来源为 [Horetzky · Auld Lang Syne](https://www.mutopiaproject.org/ftp/HoretzkyF/horetzky31/horetzky31-let.pdf)、[Mutopia · Ode to Joy](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=528)、[Hymnary · NEW BRITAIN](https://hymnary.org/tune/new_britain)，各页或谱文件标明公开领域。网页试听资料提供链接，`music-sources/README.md` 保留具体取段说明。布尔运算使用 [fonttools/skia-pathops](https://github.com/fonttools/skia-pathops)。

运行与资源生成只需 Node：`npm start`、`npm run generate`、`npm run check`。浏览器回归：`npm run check:browser`，使用本机随应用提供的 Playwright 和隔离 Edge；其他电脑须修改脚本内运行库路径。

修改原文、字体或文字布局后，依次执行 `node generate-v2.mjs --characters`、`prepare_fonts.py`、`node build-lettering.mjs`、`union_lettering.py`、`npm run generate`。Python 需要 fonttools、uharfbuzz、skia-pathops，当前开发依赖位于 `.tools/`，压缩包不含这些运行库。只改描边或光晕无需重算文字并集。

主要源码为 `art-v2.js` 共用矢量引擎、`catalog-v2.js` 目录与原文、`controls-v3.js` 控件与参数校验、`app-v2.js` 界面、`audio-v2.js` 声音、`music-excerpts.js` 曲谱事件。验证见 `VALIDATION-v2.md` 及 `test-output-v2/` 的三个报告。

`motion-v4.js` 管理发光强度、饱和度、楼窗与同步车流；`ambience-v4.js` 管理四轨混音及自动压低；`ambience-cache.js` 保存可离线解码的采样。
