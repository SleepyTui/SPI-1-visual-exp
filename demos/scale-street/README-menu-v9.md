# 紧凑信息卡 · v9

打开 `index.html` 即可离线使用；本地预览运行 `node serve.mjs` 后访问 http://127.0.0.1:4178/ 。

320×320 预览的信息卡固定为 64 像素高，约占画面的五分之一。第一排包含原文小图标、音阶滚轮、地域、年代、音数和关闭按钮；第二排将音分、映射点及对应音名放在同一张等比例音高尺上。640 模式沿用已保存的弹窗长宽和位置。宽度、位置、透明度、背景模糊及其余街景参数保持原有控制。

滚轮中间显示选中项，上下相邻项淡显。支持鼠标滚轮、点击相邻项、触摸滑动和上下方向键、Home、End；切换带约 300 毫秒的纵向缓动，系统开启减少动态效果时直接定位。原文小图标不跟随界面语言切换；长名称和地域显示完整悬浮提示。

音高尺随弹窗实际宽度重绘，音符横坐标由音程决定，音名与映射点严格共用坐标，微分音保留准确音分值。资料与选择同排展示，旧的独立标题、音名文字行与试听页脚不再占用卡片高度。

工程保存的 `user-defaults-v6.json/js` 未修改。320 模式的 64 像素高度由响应式布局计算，640 模式继续读取保存高度。原来的支架、灯效、楼宇、声音、深度图、遮挡排序和 JSON 导入导出功能保留。旧版下载包仍在目录中，本次修改前的文件保存在 `test-output-menu-v9/before/`。

验证运行 `node qa-menu-v9.mjs`，记录在 `test-output-menu-v9/report.json`：实际浏览器检查 64 像素高度、单排信息、相邻选项可见、动画中间帧、130 个音阶与语言组合、640/手机预览、离线打开、深度图与 JSON 往返及默认文件未变。`node verify-v2.mjs` 检查原有 329 个 SVG 资源。

完整资源包：`scale-street-menu-v9.zip`。所有资源及资料来源沿用各版本说明。
