# 深度图混合与广告牌遮挡顺序

刷新 http://127.0.0.1:4178/ ，在“风格”页顶部打开“深度图混合”。现有参数继续保留，新功能默认 Mix 为 0。

## Mix 两端的行为

Mix 0 不显示深度层，保留当前颜色、灯效、做旧和街景。Mix 100 显示完整的近亮远暗灰度深度图，强制正常覆盖，避免滤色或差值等模式残留原画。1–99 之间可选正常、正片叠底、滤色、叠加、柔光和差值。切回中间值会恢复所选叠加模式。

深度图从几何轮廓单独生成，天空为远端、路面由远到近渐变，建筑按已有远近层级赋值；广告牌与支架共用相同深度，移动车辆保留轮廓与运动。招牌文字、表面图案、窗灯和车灯光晕不参与深度判断。灯越亮不会被错误地当成离镜头越近。

当前工程是 SVG 2.5D 场景，这里使用人工定义的分层深度与路面投影代理，不是 Blender 网格相机的物理 Z 缓冲，也不把数值当成米。深度范围 0–100 表示场景相对距离：0 最近，100 最远。

## 映射参数

“映射近端”和“映射远端”相当于深度范围的两个截点；范围外自动夹到近端或远端亮度。“Gamma”改变距离到亮度的曲线，近端和远端亮度可以调整灰度输出范围，默认近端 100% 白、远端 0% 黑。近端值始终小于远端，近端亮度始终高于远端亮度。

## 广告牌顺序列表

同一页的“广告牌遮挡顺序”列出 16 个家族，列表顶部最近、底部最远。向前/向后按钮或拖动一行，可以同时改变彩色街景的实际绘制顺序和深度值。移动行时保留现有深度值分布，按新顺序重新分配。每行滑条可以直接编辑该牌的 0–100 深度，并按值重新排序；相同数值允许处于同一深度。

排序作用于广告牌及其支架彼此之间，保留建筑底图现有组织；不会修改广告牌的位置、大小和支架风格。“恢复原始顺序”只恢复广告牌层级与深度，不重置其他设置。排序在 Mix 为 0 时也有效。

深度设置与顺序保存到同一份 JSON 的 `depthSettings` 和 `depthLayers`，也进入“当前参数设为默认”和当前街景 SVG 导出。旧版 JSON 自动补充默认深度设置。已下载的完整包为 `scale-street-depth-v8.zip`；以前的版本仍保留。

## 验证

`node qa-depth-v8.mjs` 检查 Mix 0 与未叠加画面的逐像素一致、Mix 100 纯灰度、映射与叠加、排序与遮挡、位移缩放同步、JSON/刷新、离线和 SVG 导出。实际截图和报告在 `test-output-depth-v8/`。其余操作和来源说明见 `README-rig-v7.md` 与 `README-studio-v6.md`。
