# 可调霓虹版：浏览器与资源验证通过

验证日期：2026-10-18。环境为 Windows、隔离无头 Microsoft Edge、设备像素比 1；使用应用随附 Playwright，不读取用户浏览器资料。实际浏览器画面已检查 320／640 街景、中文／英文信息卡、景深及楼宇调整截图。

## 资源与比例

- 16 个独立楼体、屋顶、回转侧面、悬挑结构与可点击招牌；高度至少十种且跨度超过 200 个场景单位，各楼体有间隙。
- 65 条音阶、260 张招牌、65 个 32×32 单色图标、4 张街景；SVG 无位图、外部依赖和未转曲文字。
- 65 套完整文字执行 Skia PathOps 并集，外边界和内孔边界分别保留。图形在中英文切换前后完全一致。
- 16 个街景招牌的变换矩阵 X/Y 缩放系数相等；默认两种空间表现的牌面边界框两两无交叠。支架、投影、光晕不属于牌面交叠检查范围。

## 滑条、菜单与视觉控制

- 实际 DOM 中横向滑条为家族，纵向滑条为具体音阶；家族切换更新纵向范围，菜单选择反向同步滑条。
- 65 音阶 × 2 语言共 130 张菜单均完整位于 320 预览内；卡片、子元素边界及滚动范围无溢出。图标实际显示为 32 像素。
- 地域、时期、音数三列等宽等高；图标框均 40×40，顶部与中心一致，标签基线区域一致。音数多边形顶点按实际半音/微分音角度绘制。
- 不透明度 0 实际产生透明背景，模糊 0 实际关闭虚化；招牌边框线宽与文字纹样线宽分别更新独立 SVG 路径，光晕更新滤镜。
- 景深近端为 0、最远端等于指定模糊值，中间各层严格递增。
- 全局呼吸效果的实际发光亮度与饱和度随时间变化，牌底、硬件和整牌透明度保持 1；单牌可独立选择跑马、随机、闪烁及速度、幅度，其他牌继续跟随全局；单选体验中仅选中牌播放灯效。
- 车灯均为直线，与 (320,320) 消失点的共线误差低于检查阈值；动画暂停、速度、滤镜模糊、色相、亮度实际生效。
- 背景楼宇饱和度、对比度、明度与色相只作用于建筑组；组内有 16 栋楼体，不包含招牌或车灯；一键复位恢复 100%／100%／100%／0°。

## 参数与导出

- 通过真实下载按钮导出 JSON，再通过文件选择框载入；全部白名单参数与载入前精确一致。刷新后仍一致，包括背景楼宇、全局与单牌灯效、布局、菜单和试听参数。
- 错误格式文件被拒绝，当前设置保持不变。
- 单牌 SVG 下载包含编辑后的轮廓线宽、并集字形和光晕值。
- 街景 SVG 下载包含景深滤镜、灯效样式、背景楼宇色彩与车灯设置；下载文件在独立页面实际打开，16 牌仍存在。
- file:// 离线打开成功，禁止 HTTP／HTTPS 后 16 栋建筑与菜单仍可操作。桌面与 390 像素宽窗口已截图；页面无脚本错误。

## 音频

- 65 个原创练习均为 16 拍，旋律及所有伴奏音符属于当前集合；16 个家族具有 16 个不同基础 BPM。
- 16 个家族分别用 OfflineAudioContext 实际渲染，非静音、峰值小于 1；现代调式家族具有伴奏事件。
- 3 个曲谱片段均为四小节，拍号分别为 2/4、4/4、3/4；事件总拍数、音阶归属与时长计算匹配。
- 检查 Sléndro 240 cents、泰国 1200/7 cents 与 Rast 350 cents 的实际调度振荡器频率，匹配指数换算值。

机器记录位于 `test-output-v2/report.json`、`test-output-v2/controls-report.json`，实际截图同目录。上述验证不替代主观音色试听、真实硬件屏幕验收或其他浏览器内核兼容性验证。传统家族音乐为音高集合练习；三个曲谱条目之外使用明确标注的原创练习，未声称全部 65 个音阶都有经典乐段。

## 城市夜晚氛围新增验证

- 全部招牌由 100% 调至 75%，逐牌测量中心位置差小于 0.01 场景单位，16 个牌体与支架的比例同时变为 0.75；单牌移动与缩放也同步支架。
- 通过浏览器 SVG 动画时间定位，发光 RGB 强度和饱和度确实变化；牌底填色不变，牌底、金属侧面和整牌透明度始终为 1。
- 外轮廓 4、内线 0.5 时，边框为 4，全部文字与纹样为 0.5，互不混用。
- 12 个车流通道的灯轨、剪影、车灯共用相同持续时间和起始相位，位置与透明度随时间改变；剪影模糊滑条实际更新滤镜。
- 楼窗滤镜随时间微变，可调幅度、速度与基础亮度，关闭后停止变化；其他建筑实体不参与呼吸。
- 四轨音频实际解码并分别离线渲染，均非静音且缓存峰值小于 1；前三轨为 CC0 素材，第四轨是原创合成。
- 开始音阶试听后实测背景增益约 0.20；停止后平滑回升，测试等待后超过 0.90。四轨各自增益与音量滑条相符。
- 新参数包含在单个 JSON 中，导出与恢复结果一致；禁用所有 HTTP/HTTPS 请求后，file:// 仍可解码四轨环境声。

新增机器记录与截图见 `test-output-v2/atmosphere-report.json`、`emission-bright-640.png`、`emission-dim-640.png`、`night-traffic-640.png`。不将波形渲染和机器检查描述为主观听感验收。
