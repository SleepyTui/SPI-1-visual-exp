# 双色弥散视觉 · v11

直接打开 index.html 可离线使用，或运行 node serve.mjs 后访问 http://127.0.0.1:4178/ 。页面已接入紫色与杏黄色的默认双色主题，浅色纸面、半透明面板、细颗粒和扩散光斑共用两种主色的明度与饱和度变化。颜色渐变之间的混合由这两种墨色生成。

“风格”面板最上方的“双色弥散 · 两种墨色”提供两种主色、面板不透明度、街景不透明度、弥散程度、细颗粒和饱和度控制。可以关闭双色视觉回到此前的界面配色；原有灯光、景深、楼宇、支架、声音及深度图控制保留。双色开启时，最终街景色相由两种主色决定，旧色彩参数仍参与此前场景的亮度计算。深度图的独立灰度层不经过双色映射。

界面小图标使用第一色，街景通过亮度映射使用两种墨色。灯管亮度变化、独立跑马、窗灯和车辆的动画仍由原程序驱动；调色与透明度变化不会重建场景或重启灯效。320 预览的弹窗继续为 64 像素高，连续拉杆、阈值切换、松手吸附、返回及四轨环境声沿用 v10。

双色参数随全部参数 JSON 导出、导入并在浏览器持久保存；“当前参数设为默认”可将其写入工程默认文件。本次未覆盖已有 user-defaults-v6.json/js，旧参数文件载入时会自动补齐双色默认值。当前街景 SVG 导出包含独立滤镜定义，可单独打开。
