# 广告牌支架控制

本版在原有参数上增加支架控制，不覆盖当前色彩、灯效、布局或声音设置。刷新 http://127.0.0.1:4178/ ，在“布局 → 广告牌支架”中编辑。

## 全局与每块广告牌

“编辑范围”可以选择全局支架或当前广告牌。默认所有牌跟随全局，改动当前广告牌的参数会自动建立独立覆盖；勾选“此牌跟随全局”移除这个覆盖。切换音阶家族时，控制面板显示对应招牌参数。全局设置继续影响未覆盖的广告牌。

风格包括三角悬挑、梯形横梁、交替三角桁架、交叉格构、吊挂拉杆、弧形支撑，以及混合街景和隐藏。对齐模式包含原位、靠上、居中、靠下和错落。其余参数是每牌微差、杆件离散程度、桁架分格数量、线框粗细、线框颜色、金属底色、悬挑长度、上下支点间距和不透明度。

微差控制不同广告牌之间的轻微比例变化；离散控制同一支架内部节点的疏密与偏移。它们使用保存的种子生成，同一设置始终得到同一结构。“更换微差种子”产生另一套变化，“复位当前范围”只恢复当前编辑范围，保留其他参数。默认沿用三角悬挑，并带轻微差异。

支架仍与广告牌共用父级变换，牌位移、独立缩放或围绕各自中心的全局缩放时，支架同步跟随。新增参数保存到同一份 JSON 的 `rigSettings` 和 `rigOverrides`。旧 JSON 自动补支架默认值；当前街景 SVG 导出保留实际支架结构。整体风格页的实体轮廓控制仍可叠加作用于支架。

“当前参数设为默认”也保存支架参数。其余使用说明见 `README-studio-v6.md`。完整包为 `scale-street-rig-v7.zip`；原 `scale-street-studio-v6.zip` 保留。

## 实现与检查

`mounts-v7.js` 共用于浏览器和 SVG 生成，包含确定性结构生成、参数验证、全局/单牌覆盖和界面。`node qa-rig-v7.mjs` 验证样式、独立性、参数往返、缩放和导出，截图与报告在 `test-output-rig-v7/`。原有参数文件在修改前已复制到该目录的 `defaults-before.json` 作为对照。
