# MiniDisc Atelier

## MD 收藏家

打开 dist/collector.html 进入正方形屏幕的 MD 收藏界面，或在设计工作台右上角点击“MD 收藏室”。屏幕一次显示一张完整正面，其他唱片呈现带编号和名称的侧脊。

拖动屏幕下方滑条可连续翻转选片，松手吸附到最近一张；也可拖动唱片架、点击侧脊、点击左右按钮，或聚焦滑条后按左右键。星标收藏支持单独筛选并在本地保存。通过“收入我的 MD”载入设计工作台保存的 JSON，即可加入自制唱片，最多容纳 36 张。

收藏页沿用同一套四层 SVG 引擎，可直接导出当前 MD。浏览器收藏与自制唱片使用本地存储；本地文件和预览网址之间的存储相互独立。此界面为视觉收藏演示，不含音频播放。

收藏页采用统一乳白磨砂材质与扩散渐变色块，右侧标签、贴纸印字和侧脊文字独立保持清晰。景深随距离增加，只作用于内部图案和壳体材质；唱片本身不会随距离改变透明度。收藏页导出的是此磨砂视觉，设计工作台仍可编辑原来的复古模板。

直接用 Edge 或 Chrome 打开 dist/index.html，无需安装或联网。

左栏选择 12 种音乐风格模板，右栏切换盘面、外壳、标签、贴纸；中间实时显示结果。全部为程序生成的原创 SVG 图形。

- 盘面：12 种程序，每种 4 个参数，另有底色与印刷色。
- 外壳：12 种塑料纹理，透色、透光、雾化、浮凸与旧化控制。
- 标签：12 种字体风格，主标题、副标题与编号可编辑；主标题用 / 换行，支持随机标题。
- 贴纸：12 个系列，数量、尺寸、倾角、散布 4 个参数。
- 四层均有透明度、饱和度、明度、隐藏和随机锁定；支持撤销与重做。

“合成 / 分层 / 独看当前层”用于检查层次；“导出 SVG”始终导出完整合成，不受检查视图影响。SVG 内含 layer-disc、layer-shell、layer-label、layer-stickers 四个分组，以及完整参数 metadata。外壳雾化通过盘面模糊来模拟透壳观察，非真实折射渲染。

保存参数得到 JSON，可通过载入参数继续编辑。浏览器自动保存最近状态，但跨浏览器或清理浏览器数据后请用 JSON 恢复。随机锁定保护参数，外壳仍会影响合成画面。

templates/ 内是通过同一引擎导出的 12 组 SVG 与 JSON，以及总览 SVG。qa/12-genres.png 是浏览器实际渲染总览，qa/workbench.png 为工作台截图。

字体使用 Windows 本机字体；SVG 保留文字可编辑，并未转曲，其他系统可能替换缺失字体。SVG 使用标准渐变与滤镜，建议先在浏览器预览，部分矢量软件对滤镜支持不同。

视觉为受参考物件启发的二维插画，不包含品牌标志、参考照片或音频。圆盘为 3 寸 CD 风格视觉构成，非实际 MD 机械尺寸图纸。
