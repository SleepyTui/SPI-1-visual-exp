# Orbital / 宇宙图形乐谱

以实验 graphic notation 与天文轨道图为灵感的正方形交互音画 demo。纯 HTML、Canvas 2D、Web Audio，无依赖、无外部字体或素材请求。Node.js 22+ 可启动预览，现代桌面与移动浏览器均可使用。

在仓库根目录运行：

```sh
node demos/orbital-score/preview.mjs
```

或点击本机 Action「打开 Orbital 宇宙乐谱」。默认端口为 4200，可用进程变量 `ORBITAL_PORT` 改为其他空闲端口。`--no-open` 仅启动服务。预览地址只在启动服务的机器有效；云端运行无法直接打开用户电脑上的 localhost。也可直接用浏览器打开 `dist/index.html`，所有资源均为相对路径。

可拷贝的单文件 demo 位于 `demos/orbital-score/exports/orbital.html`，随源码一并提交，可下载后直接用浏览器打开，无需启动服务器。修改开发源码后，在仓库根目录运行 `node demos/orbital-score/package.mjs` 更新该文件；开发源码仍在 `dist/`。

- **8 种星系**：太阳系、螺旋、双星、椭圆、星团、星云、星际五线谱、星座连线。
- **6 类 / 72 种形状**：混合、圆圈、几何、传统音符、五线谱片段、实验图形各有 12 种可视化缩略图。每类独立多选并保存，至少保留一种；实际画布只生成已选形状。圆形包括单圆、嵌套圆环、土星、靶心、准星、放射圆与气泡；音符包括全音符至一百二十八分音符、附点、三连音、连梁与休止符。可调数量、大小、大小差异与星系半径。
- **4 种运动**：公转、漂浮、呼吸、涡旋；速度独立可调，Motion 按钮单独暂停画面。系统开启减少动态效果时默认暂停视觉运动。
- **演奏**：由中心向外、左到右、右到左、顺时针扫描。循环、单次、随机模式；每轮 16 拍，BPM 30–200。随机模式以八分音符间隔无放回抽取，抽完重新洗牌。普通扫描每个音符每轮最多触发一次，移动中的音符以当前扫描位置判定。
- **合成**：FM（正弦载波、调制比及指数包络）、VA（双振荡器、失谐及低通包络）；玻璃、钟声、温暖、深空 4 种音色方向，3 种调式。可调衰减、滤波、卷积混响与反馈延迟。音符纵向位置映射音高，大小权重映射力度，横向位置映射立体声。限 28 个同时发声的音符，输出经压缩器控制峰值。
- **视觉**：4 种配色预设、4 个自定义颜色、辉光、透明度、轨迹、轨道线、星尘、标记。宇宙轨道线与形状线宽独立可调（按 1000 × 1000 乐谱坐标计），支持纯线稿、填充、线稿加填充三种绘制模式；开放曲线在填充模式下表现为实体线带。
- **平滑变形**：8 种星系切换时以 1.8 秒五阶缓动过渡；音符沿三次贝塞尔曲线移动，轨道采样点同步变形，中心星体插值变换。支持连续打断并从当前画面继续过渡。形状与描绘方式交叉淡变；新音符长入，移除音符收缩离场。
- **全局随机**：顶部 Random universe 按钮或 Shift + R 随机布局、音符类别与选择、运动、数量、大小、配色、线宽、绘制方式和声音参数，持续 **5 秒** 平滑过渡。颜色、大小、速度与合成器连续参数同步插值；保留用户的输出音量。R / Regenerate 仅重新生成星图。
- **正方形录制**：Record 或 Export → 录制 GIF / MP4。只录制画布，录制期间可调整参数、切换布局、随机及播放。GIF 是无声循环动画，使用每帧自适应 256 色盘和内嵌 Worker 编码器，支持 512 / 768 像素、目标 12 FPS、最长 15 秒。MP4 支持 512 / 768 / 1080 像素、12 / 24 / 30 FPS、最长 30 秒，可录入当前 Web Audio 演奏。需要音轨时先播放或在录制中点击音符；勾选声音不会自行开始演奏。支持提前结束、取消与重新录制；切到后台自动取消，避免导出冻结画面。
- **直接交互**：点击音符试听，拖动改变位置；空格播放/暂停，R 生成新乐谱。切到后台会暂停演奏，避免后台计时漂移。音频需要用户手势解锁。
- **保存**：浏览器自动保存参数及拖动位置；Export 导出当前画面 PNG、参数 JSON，并支持重新导入。JSON 保存布局与随机种子，不保存播放时间；导入会重置到乐谱起点。PNG 导出当前画面，包含当前运动位置及播放扫描线。

文件入口：`dist/index.html`；样式：`dist/style.css`；图形、音频与交互：`dist/app.js`；72 种形状：`dist/glyphs.js`；本地录制与 GIF 编码：`dist/recorder.js`；材质、渐变、内外发光及引导线样式：`dist/effects.js`。打包脚本把以上代码全部内联到同一个 `exports/orbital.html`，无需网络或其他文件。

MP4 使用浏览器真实的 MP4 编码及封装能力，界面会检查支持情况，不会将 WebM 改名为 MP4。已在 Chromium 中验证 H.264 + Opus MP4；其他平台的编码器与音轨组合由浏览器决定。浏览器不支持 MP4 时可使用 GIF，或换新版 Chrome / Edge / Safari。GIF 的实际帧数取决于设备性能，帧延时按采样时间写入。所有录制都在浏览器本地完成，无需麦克风、摄像头或上传。

浏览器验收脚本为 `qa/verify.cjs`，在预览服务启动后、已有 Playwright 的环境中运行 `node demos/orbital-score/qa/verify.cjs`。可通过 `ORBITAL_CHROMIUM` 指定已安装的 Chromium，通过 `ORBITAL_QA_URL` 指定预览地址；默认使用 Playwright 自带浏览器及 4200 端口。脚本覆盖布局、参数、音频信号、扫描模式、拖动、文件导入导出、参数恢复与不同视口，并输出截图和 `qa/report.json`。音频信号测量不等同于人工试听验收。

新版验收：`node demos/orbital-score/qa/verify-v2.cjs`，沿用上述 Chromium 与预览地址变量。覆盖 72 个不同缩略图、形状过滤与持久化、两种线宽、三种绘制方式、可打断的星系过渡、完整 5 秒随机过渡，以及断网单文件 GIF / MP4 录制、取消和提前结束。结果见 `qa/v2-report.json`，实测录制文件见 `qa/v2-recording.gif` 与 `qa/v2-recording.mp4`。

V3 材质扩展：Visual → Material lab 分别编辑 **Orbital guides / 音符图形 / 播放引导**，每组独立保存：

- 配色模式：原始配色、自定义单色、线性、径向、环绕渐变；三段颜色、方向、范围和流动速度（0 为静止）；范围用于线性 / 径向渐变，环绕渐变完整覆盖一圈。渐变同时作用于描边与图形填充，适用于 72 种音符形状。
- 线条粗细、图层透明度、模糊；内发光和外发光各自拥有颜色、强度与范围。内发光以轮廓遮罩约束在图形内部，外发光只向外扩散。参数按 1000 × 1000 乐谱坐标计。
- 播放引导的 8 种样式：细线、流动虚线、星点、双轨、波动、光带、彗尾、刻度。可调纹理密度、波幅与展开（按当前样式启用适用参数）；播放条的 Style 可直接打开。样式只改变视觉，保留中心向外、左右、顺时针等扫描与触发逻辑；随机模式会连接中心和正在演奏的音符。
- 内外发光分组可展开。Reset this layer 仅重置当前图层；Reset visual settings 重置所有视觉材质。原有轨道线宽、形状线宽、音符透明度及 Glow 快捷控制与新面板同步。
- 全局随机包含三组材质及播放线样式，连续数值和颜色跟随 5 秒过渡。开启 Motion 或正在播放时渐变流动；关闭 Motion 且停止播放时画布中的动态渐变暂停。
- 新参数纳入浏览器保存、JSON 导入导出、PNG 与 GIF / MP4 录制；兼容旧版 JSON，旧 Glow 值迁移为音符外发光强度。

多组模糊和发光同时启用会增加绘制成本，实际动画及录制帧率取决于设备。发光模糊遮罩使用受限分辨率计算，主体图形和最终轮廓裁切保持画布分辨率。

V3 验收：`node demos/orbital-score/qa/verify-v3.cjs`，结果见 `qa/v3-report.json`。覆盖独立材质、真实像素内外发光边界、动态/静态渐变、8 种引导线、原播放路径、参数兼容与验证，以及断网单文件录制和移动端。
