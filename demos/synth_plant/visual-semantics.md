# 音色植物：听感与视觉的对应规则

状态：根据用户补充形成的概念规则与设计建议。此文的听感维度用于概念设计；实际工作台按用户后续明确要求，直接编辑视觉参数，不提供听感参数滑杆。

## 用户确定的方向

- 每株植物的主要对象是 timbre：声音听起来产生的气质与通感。应能表达空灵、长短、叠层、干湿、频谱高低等差异。
- Echo、Filter、Arp、Sequencer 等不是独立音色类别，不能与音色并列成植物品种。Chorus 作为效果也不应直接独立成音色类别。
- 过程图中的 Bell 下垂风铃花苞、Percussion 莲叶/镲片形态、Ambient 云雾，以及用方块暗示 Sample 片段的思路值得吸收。
- 相近标本必须有听感驱动的形态差异，避免 Pluck/Lead、Pad/Drone、Chorus/Bass 仅靠换色或名称区分。
- 可以从效果和合成模块的视觉设计提炼手法，再应用到相应听感的植物中。例如有明显回声的空灵音色可以带有重复、渐弱的形态。
- 合成算法、器件可以融入植物。若把合成方法作为显式设计维度，需要系统覆盖约定的方法集合，不能偶然挑几种与音色混排。

## 概念分层建议

1. **听感主体**：描述实际音色的时间包络、频谱、密度、共鸣、空间感与变化。它决定植物的大轮廓和主要质感。
2. **来源与生成信息**：已知的声源、合成方法、器件，作为花芯、叶片内部结构、枝条组织或盆器细节嵌入同一株植物。
3. **处理与时间组织**：可听见的效果反映到叠层、重复、空间与边缘上；Arp/Sequencer 是演奏或事件组织信息，需要展示时作附加表达，不决定植物品种。

Lead/Bass/Pad 常带有声音用途含义，Bell/Percussion/Vocal 更接近声源或发声联想，Sample 是来源/制作方式，Ambient 带有整体氛围含义。这些名称可以帮助理解，但不是同一层级的互斥分类。先定义具体标本的听感，再决定最终展示命名和分类方式。

同一种合成方法能产生很多不同音色；不同方法也能得到相近听感。不能仅凭“FM”“Sample”等标签自动推导整株形态，更不能仅凭声音猜测并断言具体器件。未知的来源信息留空。

## 听感维度到视觉手法（候选，待试样）

| 听感维度 | 候选视觉表达 | 需要区分的概念 |
| --- | --- | --- |
| 起音速度 | 快起音：紧凑节点、短促尖端；慢起音：渐开的层片、柔和展开 | 起音速度不等于音量或明亮度 |
| 衰减与延音 | 短音：独立、收束的小单元；持续音：连贯的长叶面/连续结构；长尾：渐细、渐淡的延伸 | 声源延音不等于混响尾音，静态几何长度也不是严格时长刻度 |
| 音高与频谱亮度 | 低音高：较低重心/较大主体；高音高：较高位置/较小单元；高频丰富：细密结构、清晰边缘；暗音色：平滑、厚实、内部细节较少 | 低音也可以明亮；不能把低频、高音高、亮度压成一个参数 |
| 体量与厚重感 | 枝干与形体厚度、实体填充比例、视觉重心 | 与植物总尺寸、低音高分别控制 |
| 谐波/非谐波共鸣 | 有序嵌套或规则结构；镲片般薄面、不等间距的共鸣细节 | Bell 和金属打击可以明亮且非谐波，不能仅画尖刺 |
| 气声/噪声/颗粒 | 连续细雾、毛边、碎屑密度、离散粒子的尺度分布 | 印刷颗粒是全局材质；只有与听感有关的额外颗粒才承担音色编码 |
| 单声部感与叠层感 | 清晰单一主体；多个接近但不完全重合的叶片、分枝或花冠 | 叠层不必然意味着 Chorus，重叠越多也不必然越湿 |
| 干湿与空间 | 干：边界清楚、结构集中；湿：外围低对比薄雾、扩散边界与远近层次 | 空灵不必然来自 Echo；混响的连续扩散与延迟的离散重复分开处理 |
| 可辨识的回声 | 同一局部形态按间隔重复，并逐次缩小或减弱 | 单个轨道/圆环不自动等于回声；重复须能被看出是同一形态 |
| 稳定与调制变化 | 稳定：统一方向与规律组织；变化：受控偏移、弯曲、层间差异 | 不把所有变化都画成随机碎片；静态形态先成立，动画规则以后确定 |

这些映射是设计语言，不是声学定律。需要以具体声音或用户给定的听感描述校准，避免强行一一对应。

## 局部创意的使用边界

- **Bell**：下垂风铃花苞表达敲击后的悬挂共鸣；花口、薄壁与局部回响轮廓强化钟感。Pluck 可以保留短促特征，但需用紧凑芽点、绷紧枝条等另建轮廓。
- **Percussion**：莲叶般的薄盘面适合镲片类、金属共鸣类打击音色。鼓、木块、干点击等需要其他器官形态，不能把所有打击音色都做成镲片。
- **Ambient**：云雾可表达扩散、远景与空灵，但需要区分主体和外围空间层。干燥、稀疏的氛围音色不应被默认加满混响与回声。
- **Sample**：方块、切片和不连续接缝可以暗示截取、拼接与片段边界；圆与方块的组合也可表达片段异质性。并非所有采样都可听出碎片感，完整持续采样不自动碎块化。来源已知时可另用小型结构提示。
- **Echo/Chorus/Filter**：提取渐弱复现、近似错位叠层、频谱细节的收放等手法，分别应用于确实具有相关听感的植物；不建立同名音色品种。

## 避免相似轮廓的差异策略

| 容易混淆的标本 | 主轮廓差异建议 | 可以共享的维度 |
| --- | --- | --- |
| Pluck / Lead | 短促拨奏：分离而收束的节点、紧凑簇群；持续穿透型主奏：明确主轴、延展叶面/管口与方向性 | 两者都可能明亮、尖锐；Lead 也可以短促，应以具体标本而非用途强制套形 |
| Pad / Drone | 缓慢起音且叠层的铺底：宽幅交叠、渐次展开；稳定持续型 Drone：连续贯通的主体与缓慢局部变化 | 两者都可能长、柔、湿；若听感本来接近，就不凭名称捏造差异 |
| 带 Chorus 的声音 / Bass | Chorus 的近似多层作为局部表达；Bass 的低重心、体量与基底作为主体结构 | 同一低音植物可以同时具有 Chorus 叠层，不必拆成两个品种 |

## 后续实现与核对

- 保留前端与 SVG 共用图形定义的方案，但先确定每株的听感描述，再建立参数与几何结构。
- 每株在单色剪影下检查主体差异；去掉名称和颜色后，主要形态仍应支撑预期听感。
- 使用对照试样：同一形态只改变干湿/尾音/亮度等单个维度，检查视觉变化是否清楚且相互独立。
